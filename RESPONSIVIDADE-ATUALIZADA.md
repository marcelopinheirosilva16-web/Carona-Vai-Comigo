# VaiComigo — ajustes de responsividade

Foi acrescentada uma seção ao final de `css/style.css` para melhorar a adaptação em computadores, notebooks, tablets e celulares.

## Ajustes incluídos
- Prevenção de rolagem horizontal indesejada na página.
- Grades que passam para uma coluna em telas estreitas.
- Navegação com quebra de linha para links em telas menores.
- Campos e botões mais adequados ao toque.
- Contêineres de tabelas largas com rolagem horizontal própria.
- Mapas dimensionados para telas pequenas.
- Melhor quebra de textos longos e modais adaptados à altura do celular.
- Preservação dos arquivos HTML, JavaScript e configuração Firebase existentes.

## Como usar
Abra a pasta do projeto no VS Code e execute com Live Server. Teste em uma janela de computador, depois reduza a largura do navegador ou use o modo de dispositivos móveis das ferramentas de desenvolvedor.

## Observação
Os ajustes de CSS foram aplicados ao projeto empacotado, mas precisam ser testados no navegador com as contas e dados reais do Firebase para confirmar o comportamento de cada tela e mapa.
